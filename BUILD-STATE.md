## Session 5 summary (context for whoever reads this next)
The analyst tier (`src/analyst/`) is a single post-hoc call per `drover analyze` invocation, not one call per session: it loads every session for a run, builds a compact per-session digest (derived metrics + a capped action trace + in-session findings), and sends the whole batch of digests to Sonnet in one prompt via the real Batch API (`BatchAnalystProvider` — create → poll `retrieve` → stream `results` → parse a forced `report_cross_session_findings` tool call). Findings are validated (known enum values, session ids that actually belong to this run — hallucinated ones get filtered, an empty resulting set is treated as malformed) before being written; malformed findings are logged and skipped, never crash the run. `runAnalyst` then calls `reconcileRunFindings` a second time (see decisions log — this is why the DB upsert change was needed).
